# Averion OS

**Averion OS** — это моя самая первая операционная система. Меня зовут **Данил**, мне **16 лет**, я **ученик 2 курса техникума**. Я написал эту ОС на Rust под архитектуру x86 (32-bit) для представления своему учителю. Система была разработана примерно за **2 недели** (может, чуть больше). В процессе работы я обучался по статьям на OSDev.

## Архитектура проекта

```text
averion_os/
├── src/
│   ├── drivers/        — Драйверы: клавиатура, таймер PIT, динамик Speaker, RTC, PS/2, порты I/O и VGA-вывод
│   ├── interrupts/     — Обработка прерываний: кастомная таблица дескрипторов (IDT) и обработчики
│   ├── panic/          — Реализация механизма паники ядра (panic_handler)
│   └── main.rs         — Главная точка входа в ядро на Rust (kmain)
├── boot.asm            — Точка входа (.code32): настраивает Multiboot, стек 64КБ, вызывает kmain
├── i686-averion.json   — Таргет i686-unknown-none-elf без ОС (отключены red-zone и инструкции MMX/SSE)
├── linker.ld           — Скрипт линкера для правильного расположения секций ядра в памяти
└── run.ps1             — Скрипт автоматизации сборки ISO-образа и запуска
```

## Как запускать

Запуск автоматизирован через скрипт `run.ps1` (требуются WSL и QEMU):

```powershell
./run.ps1 <путь_к_ядру>
```

**Что делает скрипт:**
1. Копирует скомпилированное ядро в папку `iso/boot/os`.
2. Собирает загрузочный образ через WSL: `grub-mkrescue -o os.iso iso`
3. Запускает эмуляцию в QEMU:
   ```bash
   qemu-system-i386 -cdrom os.iso -m 512M -vga std -audiodev dsound,id=speaker -machine pcspk-audiodev=speaker
   ```
